# Changelog

## 0.2.0 — Initial implementation build
- Added guarded drag interception, movement-radius clamp, delayed release, and temporary destination ghost.
- Added client settings for enablement, delay, ghost visibility, and opacity.
- Added a combat-turn movement estimate based on observed token displacement.
- Added warnings and fail-open behavior for missing APIs, invalid scales, and unit mismatches.
- Documented remaining-movement estimation limitations and the need for separate v13/v14 testing.

This is an early development build and has not been run inside an actual Foundry client in this environment.
